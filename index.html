PROYECTO DE INTELIGENCIA ARTIFICIAL

Reconocimiento de imágenes mediante Inteligencia Artificial

Una aplicación web capaz de analizar imágenes mediante un modelo de Inteligencia Artificial entrenado para reconocer si una fotografía corresponde a Ale o a otra persona.

INTRODUCCIÓN

¿De qué trata este proyecto?

La Inteligencia Artificial es una tecnología que permite desarrollar sistemas capaces de analizar información y realizar tareas que normalmente requieren capacidades humanas.

En este proyecto se desarrolló una página web que utiliza un modelo de Inteligencia Artificial para analizar fotografías y determinar a cuál de las dos categorías pertenece la imagen: Ale o No Ale.

PROBLEMÁTICA

¿Qué problema se busca resolver?

Identificar automáticamente a una persona mediante una fotografía puede resultar complicado cuando se realiza únicamente de manera manual.

Por esta razón, se plantea utilizar Inteligencia Artificial para analizar las características presentes en una imagen y generar una predicción de manera rápida.

JUSTIFICACIÓN

¿Por qué desarrollar esta página?

El desarrollo de esta aplicación permite demostrar de una manera práctica cómo puede utilizarse la Inteligencia Artificial dentro de una aplicación web.

Además, permite conocer el funcionamiento de un modelo entrenado con imágenes y observar cómo la Inteligencia Artificial genera probabilidades para realizar una clasificación.

OBJETIVO

Objetivo del proyecto

Crear una aplicación web responsiva que utilice Inteligencia Artificial para analizar imágenes y mostrar de manera clara el porcentaje de probabilidad correspondiente a cada categoría.

IA

Inteligencia Artificial aplicada

El sistema permite seleccionar una fotografía o utilizar la cámara del dispositivo para realizar el análisis.
